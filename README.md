# systopic/db

ORM of the systopic packages: connection, rows, scopes, schema, provisioning.

```bash
composer require systopic/db
```

Requires PHP 8.4 and `ext-pdo`. Used by [systopic/system](https://github.com/systopicode/system)
and [systopic/cms](https://github.com/systopicode/cms).
